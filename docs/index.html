Vibra

A fast, native macOS workspace for agentic coding. Terminal sessions, projects, and coding agents in one place.

Download for macOS Universal · macOS 14 or newer

Signed and notarized for Gatekeeper. Vibra updates itself: new versions are offered inside the app.

Install

  1. Download the universal disk image and open it.
  2. Drag Vibra to Applications.
  3. Launch it from Applications or Spotlight.

Releases from 0.3.4 onward are Developer ID signed and notarized by Apple.

Requirements

  • macOS 14 or newer
  • Apple Silicon or Intel

Building from source

Clone the repository and run cargo run. Requires Rust 1.96+, Xcode, and macOS 14+. See the README for packaging and release scripts.
