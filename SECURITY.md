# Security Policy

## Supported versions

Security fixes are provided for the latest published version of Vibra.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion,
or pull request. Use [GitHub's private vulnerability reporting](https://github.com/rubenrca/Vibra/security/advisories/new)
so the report and any proposed fix remain private until a release is available.

Include reproduction steps, affected versions, expected impact, and any suggested
mitigation. Reports should not include real credentials or data belonging to other
people. The maintainer will acknowledge a report as soon as practical and coordinate
disclosure after the issue has been assessed and fixed.

Official macOS releases are published only through this repository, signed with the
Vibra Developer ID, notarized by Apple, and delivered through the signed Sparkle feed.
